# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately. **Never report them in public issues,
pull requests or discussions.**

Report through GitHub private vulnerability reporting:
<https://github.com/idemfence/idemfence/security/advisories/new>

If you cannot use GitHub, email
[tbernierr@protonmail.com](mailto:tbernierr@protonmail.com) instead.

Please include a description of the issue, steps to reproduce it, the affected
version or commit, and its impact as you understand it.

We aim to acknowledge reports within 5 business days.

## Supported versions

idemfence is pre-release and has no published versions yet, so no versions are
currently supported. This section will list supported versions once a release exists.
